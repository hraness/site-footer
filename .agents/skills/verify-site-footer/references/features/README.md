# Site-footer feature map

Broad sweep order:

1. [Signup states](signup-states.md) covers idle, pending, accepted, and request error.
2. [Responsive layout](responsive-layout.md) covers wide and compact composition, in-flow placement, rendered edge clearances and safe-area padding, target sizes, overflow, and two-sample stability in signup and no-signup layouts.

The fixture renders the package's real React adapter. It substitutes the Accounts request boundary with a synthetic deterministic adapter, so it cannot prove Accounts delivery, confirmation email, or a consumer's CSP and theme integration.
