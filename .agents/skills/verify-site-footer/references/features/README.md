# Site-footer feature map

Broad sweep order:

1. [Signup states](signup-states.md) covers idle, pending, accepted, request error, and Turnstile verification error.
2. [Responsive layout](responsive-layout.md) covers wide and compact composition, fixed-bar reservation, target sizes, overflow, and two-sample stability.

The fixture renders the package's real React adapter. It substitutes the external provider and request boundaries with synthetic deterministic adapters, so it cannot prove live Turnstile policy, Accounts delivery, confirmation email, or a consumer's CSP and theme integration.
